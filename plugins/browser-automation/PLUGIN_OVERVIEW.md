Let Omnyo browse, click, fill out forms, and check web pages for you. Control the in-app browser or run headless browsers on your local and remote machines connected to Omnyo.

Headless sessions include live inline previews in the chat, so you can watch Omnyo work and expand the preview for a closer look. In-app browser sessions stay visible in Omnyo's browser panel.

Enable Browser Automation in plugin settings, then ask Omnyo to open a page, test a flow, or verify a change.
