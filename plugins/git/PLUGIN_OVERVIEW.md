See your thread's git state at a glance from the thread's controls at the top right of the window.

## What you get

- One control that shows the branch, the size of your uncommitted changes, and how far the branch is ahead of or behind its base.
- A pull request badge coloured by what the pull request needs: failing checks, a review, or nothing at all.
- A panel that separates changed files, new files, and committed work, with each file named by its file name first.
- One-click Commit, Mark ready, and Merge, using the same actions as the rest of Omnyo.

## How it works

The plugin reads the thread's git status from Omnyo and adds a control to the thread's header controls: the window's top bar for a single thread, or each pane's header in a split. Open the control to see each changed file and open its diff, choose the branch the thread merges into, or review every change in the diff panel.

Turn the plugin off in Settings to hide the control. No account or separate install is required.
