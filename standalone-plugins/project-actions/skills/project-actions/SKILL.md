---
name: project-actions
description: Edit or run persistent project-wide buttons in Omnyo’s top-right header.
---

Use the native project_actions tool to list or replace shortcuts in the caller's project.
List first and preserve existing actions. Replace with the returned revision; concurrent edits reject stale revisions. Array order controls display. Omit an action to remove it. Maximum 12 actions; first two appear directly, others in overflow.
Command: `{id,label,kind:"command",hostId,cwd,argv,timeoutMs}`. Use exact absolute cwd, explicit machine and executable argv. No shell is inserted. Timeout defaults to 60 seconds, maximum 12 hours. A running command shows a spinner and a × that force quits its whole process tree after confirmation, so launch a desktop app or game in the foreground (do not detach it) with a timeout covering a session; use managed previews for servers. Output is discarded: redirect to a log file inside the command when it is needed. For long commands, write live status lines to the file named in `$OMNYO_ACTION_STATUS`; the header shows the last line on hover, and a leading `n/m` (for example `2/4 Building`) fills a step bar. Every running command also shows its elapsed time. Add `check:{argv,intervalMs}` for a quick status command (same machine and folder, every intervalMs, default 5000, killed after 10 seconds) about what the action manages: exit 0 shows a green dot (running and current), 1 a hollow dot (not running), 2 an amber dot (running, but clicking would change something, such as loading a newer build), and the last line it writes to `$OMNYO_ACTION_STATUS` is the hover text; agent and CLI `list` waits for any due check and returns each as `states` (tone, text, checkedAt). Never store credentials in action arguments; a command that needs a secret must read it at run time, for example from the system keychain.
URL: `{id,label,kind:"url",url}` for an HTTP(S) URL opened by Omnyo.
CLI: `omnyo project-actions list [--project ID]`; `omnyo project-actions replace --value '{"revision":0,"actions":[]}' [--project ID]`; `omnyo project-actions run ID [--project ID]`; `omnyo project-actions stop ID [--project ID]` force quits a running command.
Native tool project scope comes from the caller. CLI uses the current project unless --project is explicit. Configuration persists across chats and reloads. Buttons run saved actions without an LLM. Creating a shortcut does not authorize deployment, spending, sends or other effects outside the user's request. Command output is withheld to avoid secret leakage; status shows actual exit metadata.
