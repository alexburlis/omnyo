# Chat Groups

This standalone plugin owns `chat-groups/groups`, the sidebar footer view disclosure and the project pill in each chat header.

Use the pinned public Omnyo SDK. The Projects button selects Omnyo's existing `thread-list/thread-list` provider. Preserve its preferences.

Use Omnyo's live sidebar data and row statuses. Do not infer completion from idle or read status. Use three primary sections: Unread, Read, Working. Nest Needs you / Other chats / Ready to archive under Unread and Needs you / Unfinished / Ready to archive under Read. Keep the seven statuses in that order. Primary sections and status groups collapse independently; counts include roots only. Within each status, group roots by project with one pill and connected frame. Projects sort by their most recent root, with recent attention first within a project. Keep indicators at the trailing edge after row controls, including on hover and during shortcut mode. Archive suggestions call Tidy's live checked archive RPC and open the next root only after success; failures remain visible. A sticky section heading preserves context while scrolling. Align parent and leaf titles, indent child levels, and label sub-chat counts explicitly. Pending input outranks live work when classifying a chat; ready marks distinguish both unread and read idle chats. Hide empty sections and groups. Initial parent navigation leaves the unread top visible; direct child navigation opens its section, status group and ancestry. Child unread success/errors do not create user attention. Child input requests and live work roll up to the root. Read queued/running workflow activity through the supported per-origin RPC; hidden workflow agents must keep their origin Working. Unknown activity must suppress Ready through visible ancestry. Preserve the current public SDK action/navigation contracts.

Run `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `omnyo plugin build .`, and the Chrome E2E script in a separate test Omnyo instance. Never install into your live Omnyo to run a test. The script must not send agent prompts or archive real chats.
