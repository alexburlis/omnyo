## See which chats need you

Open Chat view in the sidebar footer to switch between Projects and Status. Three section bars organize the list: Unread, Read, Working. Smaller status groups sit beneath Unread and Read. Needs you comes first within each; Ready to archive comes last. Empty sections and groups stay out of the list.

Section bars and status groups collapse independently. Each count covers parent chats at its level. The section bar stays visible while scrolling. Within each status, a visible project pill and connected frame contain that project's chats. Project names appear once per group. Chat titles align consistently and can wrap to two lines, with full text available on hover. Explicit sub-chat counts sit beneath parent titles. Opening a parent keeps unread groups at the top. A read or idle chat is never automatically called complete. Chats resume under Working when new work begins, even if unread or an old archive mark remains.

Expand a parent chat to see its indented sub-chats, with deeper levels available in place. Direct child navigation opens the relevant section, status group and ancestors. Child unread replies and errors stay inside the parent tree. Actual input requests and ongoing work appear on the parent's status. Queued and running workflow agents keep their originating chat Working, including hidden agents and gaps between calls. Ready returns after all runs finish; an unavailable progress read keeps affected chats unfinished.

Colored status icons and counts distinguish attention, unread, unfinished, ready and working states using your theme. Decision indicators stay at the far right. Click a green archive suggestion to archive through Tidy's completion checks and open the next parent chat. A failed archive keeps the current chat open; an empty list opens that project's new-chat screen. Project pills also appear at the top of each chat, including split panes. Chat actions and jump shortcuts stay available. The Projects button restores Omnyo's normal list and its saved layout.

## Existing signals, no extra agents

The plugin reads Omnyo's live chat states and the sidebar markers from Tidy and Decisions. Keep those plugins and their row markers enabled for archive and decision grouping. No message classification, paid service, account, or background agent is added.

Requires Omnyo 0.46 or later. It does not archive chats automatically.
