# Browser acceptance and failure modes

This suite owns the browser behavior of the public components that Omnyo's native
message directive slots render. It imports the production blocks, chart, category comparison, ordered steps, and CSS.
The harness supplies Omnyo's documented message DOM and theme tokens; it does not
mock rendering, expose private parser helpers, or add test-only production seams.

| Observable contract                                                                                       | Credible regression                                                                    | Browser check                                                                                                                                    |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Native metric, callout, badge, progress, and chart blocks remain between prose, lists, a table, and code. | A renderer drops surrounding content or reintroduces a file/webview iframe.            | Assert surrounding prose and exact block text; no iframe exists.                                                                                 |
| Metrics preserve the supplied labels, values, and context.                                                | An attribute parser truncates, reorders, or fabricates a metric.                       | Assert all three labels, exact values, and details at 360 px and 900 px.                                                                         |
| Assistant Markdown gets scoped typography; user Markdown keeps host styles.                               | A broad `.group/message` or Markdown selector styles user messages.                    | Compare computed paragraph/list/table styles with the root opt-in attribute enabled and disabled.                                                |
| Compact blocks and normal prose fit a narrow viewport.                                                    | A fixed width or unbroken number forces horizontal page overflow.                      | Check every production block's rectangle and the document width at 360 px.                                                                       |
| Charts preserve source decimal text and work for flat and negative series.                                | A zero range generates NaN coordinates, or chart formatting rounds exact data away.    | Read keyboard tooltips, inspect browser-rendered SVG coordinate attributes for nonfinite text, and assert exact values.                          |
| Chart points are reachable by keyboard and explain the focused point.                                     | Pointer-only hover removes access for keyboard users.                                  | Focus the first point through Tab, then read its visible tooltip.                                                                                |
| Invalid, mismatched, oversized, and markup-bearing data shows the literal escaped directive.              | Parsers silently truncate, fabricate a partial chart, or render attribute HTML.        | Change the live harness case, assert the entire source string, no SVG/progressbar for that invalid block, and no executed HTML payload.          |
| Unknown progress attributes cannot silently change the represented maximum.                               | A misspelled `maximum` attribute is ignored and a false 50/100 progress block appears. | Supply `value=50` and `maximum=200`; assert the exact literal source and no progressbar.                                                         |
| Keyboard focus owns the tooltip while a pointer remains over another chart point.                         | Hover state wins over focus and describes the wrong point.                             | Hover the first point, move focus with ArrowRight, and assert the second point tooltip and description relationship.                             |
| Nonzero decimals that underflow the chart number type remain literal source.                              | `1e-400` converts to zero while the chart presents a nonzero source value.             | Supply `1e-400,2e-400`; assert exact literal source and no SVG.                                                                                  |
| Light and dark token presets remain legible and preserve content.                                         | A hardcoded fill/text color or theme update hides a block.                             | Assert text and contrasting foreground/background colors in both themes; retain one full-page screenshot per theme.                              |
| A browser or server failure still releases owned resources and records bounded evidence.                  | A failed assertion leaves a listener, Chrome profile, or unbounded artifacts.          | Runner closes page/context/browser and Vite in `finally`; proof and two screenshots can only be written below the explicit `--output` directory. |

## Extension authoring gate

The same browser owner now covers two new public directive components. Valid
fixtures are invented examples, never live measurements. Each row adds a distinct
observable contract that the existing chart/progress tests cannot establish.
Production implementation starts only after these cases are authored.

| Observable contract                                                                                                                     | Credible regression                                                                                                   | Browser check                                                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Category comparisons retain full category names, source order, exact decimal text, units and notes at 360 px and 900 px in both themes. | A time-chart renderer truncates category names, sorts rows, rounds decimal text or calls the final category “Latest.” | Read visible rows and exact values in input order; inspect clipping; reject a Latest label; retain the existing mixed-content screenshots.                                      |
| One or two series share one numeric scale and a common signed zero origin.                                                              | Each series normalizes independently or negative bars start at the left and misrepresent their values.                | Inspect rendered track/fill DOMRects: equal track widths, proportional fill widths across all values, and shared left/right/interior origins for positive/negative/mixed input. |
| Zero, finite tiny values, and the 1–12 category bounds render honestly.                                                                 | Zero range causes nonfinite geometry, subnormal division collapses valid values, or bounds reject a valid endpoint.   | Check zero-width fills, 5e-324 and 1e-323 at a 1:2 width ratio, and visible first/last categories at 1 and 12 entries.                                                          |
| Comparison bars are reachable by Tab and ArrowLeft/ArrowRight/Home/End; a table preserves categories and named series.                  | Mouse-only bars or an inaccessible/rounded data table hides the exact inputs.                                         | Traverse every focusable image, assert accessible category/series/value names, and open/read the accessible table.                                                              |
| Paired series require distinct explicit names and matching lengths.                                                                     | An unnamed, mismatched, or independently scaled second series looks like a valid comparison.                          | Supply missing, duplicate, orphan and mismatched second-series inputs; require the complete literal source and no partial bars/table.                                           |
| Invalid comparison fields, numbers, unsafe text and oversized inputs fail visibly.                                                      | Unknown attributes are ignored, underflow becomes zero, or malformed content produces a partial comparison.           | Table-driven missing/empty/mismatch/malformed/overflow/underflow/unknown/oversize/markup/control cases assert exact escaped source and no executed payload.                     |
| Ordered steps preserve the supplied order without implying completion when states are absent.                                           | A numbered list invents status labels or an automatic percentage.                                                     | Read the semantic ordered list; assert exact label order, numbered markers, no progressbar/percentage/status and no fabricated “done.”                                          |
| All eight step states remain explicit and distinct; queued never means done.                                                            | Color-only states or a queued-to-done mapping hides the supplied status.                                              | Read each list item's visible label and state text, including pending, queued, running, done, waiting, blocked, failed and unknown.                                             |
| Step details permit blank entries; as-of text, notes and references remain visible and inert.                                           | Blanks shift later detail/reference ownership or references become generated links.                                   | Assert each detail/ref belongs to its original item, as-of/note text appears, plain Markdown punctuation remains literal, and refs do not create links.                         |
| Step strict fields, matching list lengths, safe bounded text and 1–12 entries reject malformed input.                                   | Empty labels, bad states, unknown attributes or too many entries fabricate partial progress.                          | Table-driven invalid cases require complete literal source, no list/progressbar/image/script, and an unexecuted HTML payload.                                                   |

## Status table and file card

| Observable contract                                                                                        | Credible regression                                                                                                | Browser check                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Status rows keep exact labels, values, details, headers and row order at 360 px and 900 px in both themes. | Pipe parsing shifts a detail to another row or drops a header.                                                     | Read each row header and value cell by role; assert detail ownership and both column headers.                                                    |
| Each tone renders a distinct color by meaning.                                                             | Tones collapse to one color or a typo silently becomes neutral.                                                    | Compare computed value colors for all six tones; an unknown tone is invalid source.                                                              |
| Short values stay on one line; long values keep a usable column.                                           | Narrow layouts collapse the value column to one character per line.                                                | Measure each value's height against its line height and long-value column share.                                                                 |
| A file card hands Omnyo's own Markdown renderer exactly one escaped link.                                  | Title punctuation creates formatting or breaks the link; a path with spaces or parentheses splits.                 | Read the exact Markdown source received by the host renderer stand-in for absolute, relative, Windows and HTTPS destinations.                    |
| A local file card links only a file that exists on the message's machine.                                  | A missing path renders as a link, or as a Pursue plan-actions error with nested HTTP codes.                        | Absolute, workspace-relative and removed-after-render paths show `File not found: <checked path>`, no link or button, and Pursue is never asked. |
| Unsafe or malformed card and table input fails visibly.                                                    | `javascript:`/`data:` destinations, angle-bracket escapes, unknown attributes or control characters render a link. | Table-driven invalid cases require complete literal source, no anchor, table or renderer, and an unexecuted payload.                             |
| Labels written row by row render only when their repeated values prove every row.                          | A label/value interleave stays raw source, or an unproven interleave is guessed and drops or shifts a cell.        | `status-row-order` renders three exact rows, details and tones; `status-opportunity-mismatch` (unproven) stays literal source under its warning. |

## Agent-written blocks (0.3.12)

File-card directives and fences share destination validation. The `file-path`
browser fixture checks that a `path` attribute renders the host file link with
the supplied title; when `href` and `path` conflict, `href` wins (0.3.17).
The parser tests cover field-line and directive fences, including unsafe aliases.

| Observable contract                                                                            | Credible regression                                                                                  | Browser check                                                                                                                                           |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every block shares one tone vocabulary; the documented aliases render as their canonical tone. | A tone valid on one block is raw source on another, or `success` leaves an agent's table unrendered. | The agent's exact `tones="success\|success\|warning"` table renders positive, positive, warning; info, negative and success callout/badge tones render. |
| No block ever shows a parse error; unrenderable input reads as plain text.                     | A malformed block shows a warning, raw directive source, or nothing.                                 | Every invalid fixture renders its content with no `[role=note]` or `Couldn’t show` text; the text-less callout renders its title as a callout.          |

The fixture installs a minimal `Markdown` stand-in on the documented plugin
runtime global, matching the SDK test runtime's renderer. Live Omnyo proves that
core's renderer opens the resulting link.

No unit tests, private parser exports, mocks or test-only production hooks are
introduced. CSS classes queried for geometry are the real rendered track/fill
style owners. The existing single Chrome context, explicit output directory,
bounded screenshots and finally cleanup remain the sole runner contract.

The suite proves native component browser behavior and CSS scope against the
installed host's known DOM selectors. It does not prove SDK registration,
installation in Omnyo, directive extraction, production service state, or the Omnyo
host's accessibility tree. Those remain integration checks at the parent lane.
