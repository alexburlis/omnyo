# Weekly Content Feed

Work only from the pinned startup inputs and supplied evidence. Never inspect a
workspace, invoke tools, access an account, or publish content. Return the exact
JSON requested by the current drafting or review stage.

A complete batch contains seven original accepted pieces with distinct canonical
topics and seven distinct calendar dates. The reviewer must be a separate model
invocation and match the exact draft digest. Reject unsupported factual claims,
near duplicates and incomplete pieces. A rejected or revision-required candidate
does not count toward completion. Keep accepted work when the run stops; resume
the same week and replace rejected candidates within the fixed candidate budget.
Report a partial batch honestly when the budget ends. Publication requires a
separate destination grant and is never part of this workflow.
