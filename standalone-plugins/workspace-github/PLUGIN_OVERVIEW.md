# GitHub

A GitLens-style Launchpad for GitHub work across Omnyo projects, including repositories nested below project folders. Issues and pull requests share one list grouped by the next action (ready to merge, blocked, needs follow-up, waiting, drafts, open issues), with dense rows showing checks, diff size and age, a repository rail, and an Inspect sheet for checks, merge, files and activity. Closed and merged history stays in its own view.

Based on the [bb GitHub plugin](https://github.com/get-bb/bb/tree/1078899ff7a37fba5b82a91cc2ea70a869707425/plugins/github). Thanks to Michael Yong and the bb contributors. The original MIT copyright and license are included.
